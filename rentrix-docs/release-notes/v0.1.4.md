# 🚀 Rentrix v0.1.4

This release introduces multi-file uploads, a redesigned proof-of-living experience, and resolves a critical issue where larger image uploads were failing unexpectedly.

## ✨ Highlights

### Multi-File Upload Experience

The previous single-upload flow has been replaced with a slot-based grid uploader for a more intuitive experience.

#### Flat Images
- 5-column grid layout
- Up to 10 images
- Multi-select support
- Drag-and-drop support
- Set primary image
- Delete uploaded images
- Remaining slot counter

#### Proof of Living
- 3-column grid layout
- Up to 3 files per review
- Multi-select uploads
- Drag-and-drop support
- Upload management actions

Both upload flows now share a reusable `ImageGridUploader` component, ensuring a consistent user experience across the platform.

---

### Large File Upload Fix

Users occasionally experienced Internal Server Error responses when uploading images larger than approximately 1 MB.

```yaml
spring:
  servlet:
    multipart:
      max-file-size: 15MB
      max-request-size: 50MB
      file-size-threshold: 2MB
```

Additional improvements:

- Added global `MaxUploadSizeExceededException` handling
- Returns HTTP `413 Payload Too Large`
- Displays user-friendly validation messages
- Prevents unexpected HTTP 500 responses

### Proof Verification Workflow

**When approved:**
- All related proofs become verified
- Review receives the "Verified Stay" badge

**When rejected:**
- Proofs are unverified
- Files remain available for audit purposes
